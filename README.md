# GeoPlot

Measure land by marking points on a map or walking the boundary with GPS.

**Live:** [https://geoplot-flame.vercel.app/](https://geoplot-flame.vercel.app/)

Approximate only — not for surveys or legal boundaries.

## Run locally

```bash
npm install
npm run install:all
npm run dev
```

App: http://localhost:5173

Config stays in `.env` and `client/.env` (not committed).

## Notes

- GPS needs HTTPS or localhost
- Location stays on your device
